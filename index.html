01 / GRACE–GRACE-FO research overview

Reconstructing missing satellite-gravity observations using predictive modelling.

The problem

Missing observations interrupt the continuity of satellite-gravity time series. This project investigated machine-learning approaches for estimating values within those gaps.

My contribution

Applied Python-based modelling, compared predictive approaches and assessed their outputs using error metrics and statistical diagnostics.

Evaluation and outputs

Examined how predictions matched reference observations, compared model performance and documented the methodology, findings and limitations in a scientific report.

Interpretation

Reconstructed values are estimates. Performance on withheld observations supports evaluation of the method but cannot directly verify predictions inside a gap without reference measurements.

03 / Healthcare facility suitability in Greater Accra

Using spatial evidence to investigate potential locations for a new healthcare facility.

The question

How can population distribution, existing healthcare facilities and accessibility inform the assessment of candidate locations?

My contribution

Developed maps covering the study area, population, healthcare facilities, hospital service areas, road accessibility and final suitability.

Project output

Presented the analysis through an ArcGIS Online story map connecting spatial findings with the facility-siting question.

Interpretation

Suitability results depend on data quality, coverage and analytical assumptions. Further site investigation is needed before making a final location decision.
